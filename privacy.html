プライバシーポリシー / Privacy Policy

mofu visual archive（以下「当サイト」）は、運営者本人が制作した音楽作品のビジュアルアーカイブです。

収集する情報

当サイトおよび関連ツール（mofu visual archive poster）は、訪問者の個人情報を収集しません。お問い合わせフォーム、アカウント登録、Cookieによるトラッキングはありません。アクセス解析には外部の匿名集計サービス（GoatCounter）を利用しており、個人を特定する情報は取得しません。

Pinterest API の利用について

関連ツール「mofu visual archive poster」は、Pinterest API を運営者自身のPinterestアカウントに対してのみ使用し、運営者が制作したピン（画像・タイトル・説明・リンク）の作成・管理を行います。第三者のPinterestデータの取得・保存・共有は行いません。APIで取得した情報（ボード一覧等）は運営者のローカル環境でのみ保持されます。

第三者提供

取得した情報を第三者に販売・提供することはありません。

お問い合わせ

本ポリシーに関するお問い合わせは、当サイト運営者（S.K_mofu / K.S_mofu）までお願いします。
